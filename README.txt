웨딩 청첩장 웹사이트
======================

실행 방법
1. ZIP 압축을 풉니다.
2. index.html 파일을 Chrome, Edge 등 브라우저에서 엽니다.
3. images 폴더는 index.html과 같은 위치에 그대로 둡니다.

파일 구성
- index.html : 페이지 구조와 내용
- style.css : 디자인 및 반응형 스타일
- script.js : 사진 확대 및 계좌번호 복사 팝업
- images/ : 실제 이미지 파일

수정할 내용
- 예식 날짜, 시간, 장소, 주소
- 신랑/신부 이름 및 계좌번호
- 구글 지도 링크의 검색어
- images 폴더의 사진

참고
- 사진은 제공된 디자인 시안의 사진 영역을 잘라 별도 이미지 파일로 구성했습니다.
- Google Fonts는 인터넷 연결 시 적용됩니다. 나머지 레이아웃과 사진은 로컬 파일로 표시됩니다.
- 지도 버튼은 Google Maps의 장소 검색으로 연결됩니다. 실제 예식장 주소로 변경해 주세요.
- 실제 계좌번호와 개인정보를 입력하기 전에 공개 범위를 확인하세요.
